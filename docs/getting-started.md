# Getting Started

## Installation

Install Flake using `pip`:

```bash
pip install flakepl
```

## Upgrade

To upgrade Flake to the latest available version:

```bash
pip install --upgrade flakepl
```

## Installation from source

To install the development version directly from the repository:

```bash
git clone https://github.com/FlakePL/FlakePL.git
cd FlakePL
pip install -e .
```

## Verify installation

Check that the package is available:

```bash
pip show flakepl
```

You can also test the import:

```bash
python -c "import flakepl; print('Flake installed successfully')"
```
