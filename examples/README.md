# Examples

These examples are intentionally small and executable with the published `flakepl` API.

```text
communication.py          one-step process semantics
state_space.py            finite state-space exploration
communication_epistemic.py process + epistemic model
epistemic.py              knowledge from observations
two_phase_commit.py       protocol verification with temporal formulas
```

Run an example from the repository root with:

```bash
python examples/communication.py
python examples/state_space.py
python examples/communication_epistemic.py
python examples/epistemic.py
python examples/two_phase_commit.py
```
